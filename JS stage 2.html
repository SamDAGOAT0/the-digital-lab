LESSON 05 / MAKING DECISIONS

Conditional Statements

Teach your program to evaluate situations and choose what to do next.

01. What are conditional statements?

A conditional statement allows JavaScript to run different pieces of code depending on whether a condition is true or false.

Think about a login screen. If the password is correct, the user gets access. Otherwise, the website displays an error message.

The program is making a decision based on a condition.

02. The if statement

The if statement runs a block of code only when its condition evaluates to true. 

let score = 85;

if (score >= 50) {
    console.log("You passed!");
}

JavaScript checks whether score is greater than or equal to 50. Since the condition is true, the message appears in the console.

CONSOLE OUTPUT You passed!

03. The if...else statement

What happens when the condition is false? That's where else comes in. It gives your program an alternative action. 

let score = 35;

if (score >= 50) {
    console.log("You passed!");
} else {
    console.log("Try again!");
}

The score is below 50, so the else block runs.

CONSOLE OUTPUT Try again!

04. The else if statement

Sometimes a program needs to check several possible conditions. Use else if to test another condition when the earlier one was false. 

let score = 78;

if (score >= 90) {
    console.log("Excellent!");
} else if (score >= 70) {
    console.log("Great work!");
} else if (score >= 50) {
    console.log("You passed.");
} else {
    console.log("Keep practising.");
}

JavaScript checks the conditions from top to bottom. Once one condition is true, its block runs and the remaining branches are skipped.

CONSOLE OUTPUT Great work!

05. Multiple conditions

You can combine conditions using logical operators from Lesson 04.

The AND operator (&&) requires both conditions to be true. 

let hasTicket = true;
let age = 16;

if (hasTicket && age >= 13) {
    console.log("Access granted.");
} else {
    console.log("Access denied.");
}

The OR operator (||) requires at least one condition to be true. 

let isWeekend = false;
let isHoliday = true;

if (isWeekend || isHoliday) {
    console.log("No school today!");
}

06. The switch statement

A switch statement is useful when you want to compare one value against several possible cases. 

let position = "Goalkeeper";

switch (position) {

    case "Goalkeeper":
        console.log("Protect the goal.");
        break;

    case "Defender":
        console.log("Protect the defence.");
        break;

    case "Midfielder":
        console.log("Control the midfield.");
        break;

    case "Forward":
        console.log("Lead the attack.");
        break;

    default:
        console.log("Unknown position.");

}

Here's what the important keywords mean:

  • switch — Starts the selection statement.
  • case — Defines a value to compare against.
  • break — Exits the switch after a matching case.
  • default — Runs when no case matches.
Important: Without break, JavaScript can continue into the next case. This behaviour is called fall-through.

07. The ternary operator

The ternary operator is a compact way to choose between two values based on a condition. 

let isLoggedIn = true;

let message = isLoggedIn
    ? "Welcome back!"
    : "Please log in.";

console.log(message);

Read it like this: if isLoggedIn is true, use the first value. Otherwise, use the second value.

CONSOLE OUTPUT Welcome back!

THE KEY IDEA

Conditional statements allow your code to make decisions based on information and conditions.

LESSON 06 / REPEATING INSTRUCTIONS

Loops & Repetition

Learn how to repeat instructions without writing the same code over and over again.

01. Why do we need loops?

Imagine printing the numbers from 1 to 100. Writing one hundred separate console.log() instructions would be inefficient.

A loop solves this problem by repeating a block of code while a condition allows it to continue.

02. The for loop

A for loop is commonly used when you know how many times you want to repeat something. 

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Let's break down the three parts:

01 / START

let i = 1

Creates the counter and starts it at 1.

02 / CONDITION

i <= 5

The loop continues while the condition is true.

03 / UPDATE

i++

Increases the counter by one after each repetition.

CONSOLE OUTPUT 1 2 3 4 5

03. Counting backwards

A for loop can also count backwards. Change the starting value and update rule. 

for (let i = 5; i >= 1; i--) {
    console.log(i);
}

console.log("Go!");

The counter begins at 5 and decreases by one each time until it reaches 1.

04. The while loop

A while loop repeats a block as long as its condition remains true. 

let count = 1;

while (count <= 5) {

    console.log(count);

    count++;
}

In this example, count increases after every repetition. Eventually it becomes 6, the condition becomes false, and the loop stops.

Watch out: Always make sure a while loop can eventually reach a false condition. Otherwise, it may become an infinite loop.

05. The do...while loop

A do...while loop runs its code block once before checking the condition. This means it always runs at least once. 

let number = 1;

do {

    console.log(number);

    number++;

} while (number <= 3);
CONSOLE OUTPUT 1 2 3

06. The for...of loop

The for...of loop makes it easy to visit each value in an iterable, such as an array. 

const clubs = [
    "Barcelona",
    "Arsenal",
    "Bayern Munich"
];

for (const club of clubs) {
    console.log(club);
}

Instead of manually accessing each array position, the loop gives you the next value on every repetition.

07. break and continue

JavaScript provides two useful keywords for controlling loops.

break immediately exits the loop. 

for (let i = 1; i <= 10; i++) {

    if (i === 5) {
        break;
    }

    console.log(i);
}

This loop stops when i reaches 5.

continue skips the current repetition and moves to the next one. 

for (let i = 1; i <= 5; i++) {

    if (i === 3) {
        continue;
    }

    console.log(i);
}
CONSOLE OUTPUT 1 2 4 5

08. Choosing the right loop

FOR

Known repetitions

Useful when you have a counter or a clear number of repetitions.

WHILE

Condition-controlled

Useful when the number of repetitions depends on a condition.

DO...WHILE

Run at least once

Useful when the code should execute before the first condition check.

FOR...OF

Visit each value

Useful for going through values in arrays and other iterables.

  • Use a while loop to count backwards from 5 to 1.

THE KEY IDEA

Loops repeat instructions efficiently. Choose a loop based on how and when you want the repetition to stop.

LESSON 07 / REUSABLE CODE

Functions

Organise your JavaScript into reusable blocks that perform specific tasks.

01. What is a function?

A function is a reusable block of code designed to perform a particular task.

Instead of writing the same instructions repeatedly, you can place them inside a function and call that function whenever you need it.

Imagine a function that displays a welcome message. You can use it multiple times without rewriting the message each time.

02. Creating your first function

A function declaration begins with the function keyword, followed by its name and a pair of parentheses. 

function greet() {

    console.log("Welcome to THE DIGITAL LAB!");

}

Writing the function creates it, but does not execute its instructions yet. To run it, you must call it. 

greet();

The name followed by parentheses tells JavaScript to execute the function.

CONSOLE OUTPUT Welcome to THE DIGITAL LAB!

03. Parameters and arguments

Functions become more flexible when you give them information to work with.

A parameter is a named variable listed in a function's definition. An argument is the actual value passed when the function is called. 

function greet(name) {

    console.log("Hello, " + name + "!");

}

greet("Sam");
greet("Alex");

Here, name is the parameter. "Sam" and "Alex" are arguments.

CONSOLE OUTPUT Hello, Sam! Hello, Alex!

04. Using multiple parameters

A function can accept more than one parameter. 

function introducePlayer(name, club) {

    console.log(name + " plays for " + club + ".");

}

introducePlayer("Lamine Yamal", "Barcelona");

The first argument is assigned to name, while the second is assigned to club.

05. Returning values

A function can calculate something and send a result back using the return keyword. 

function addNumbers(a, b) {

    return a + b;

}

let result = addNumbers(10, 5);

console.log(result);

The function calculates the sum and returns it. The returned value is stored in result.

CONSOLE OUTPUT 15
Important difference: console.log() displays a value. return sends a value back from a function so that the rest of your program can use it.

06. Default parameters

You can provide a default value for a parameter. JavaScript uses this value when an argument isn't supplied. 

function greet(name = "Guest") {

    console.log("Welcome, " + name + "!");

}

greet("Sam");
greet();
CONSOLE OUTPUT Welcome, Sam! Welcome, Guest!

07. Arrow functions

JavaScript also provides a shorter way to write many functions, called an arrow function. 

const greet = () => {
    console.log("Hello!");
};

greet();

An arrow function can also accept parameters and return values. 

const multiply = (a, b) => {
    return a * b;
};

console.log(multiply(4, 5));

For a simple expression, you can write an even shorter version: 

const multiply = (a, b) => a * b;

console.log(multiply(4, 5));

When an arrow function has a single expression and no curly braces, that expression is returned automatically.

08. Why functions matter

Functions make programs easier to organise, understand, test and reuse. 

function calculateMatchPoints(wins, draws) {

    const winPoints = wins * 3;
    const drawPoints = draws * 1;

    return winPoints + drawPoints;

}

const points = calculateMatchPoints(5, 2);

console.log(points);

This function calculates a team's league points using three points for each win and one point for each draw.

CONSOLE OUTPUT 17

THE KEY IDEA

Functions package instructions into reusable blocks. Parameters provide input, and return sends results back.

LESSON 08 / RESPONDING TO USERS

Events & Event Listeners

Learn how to make websites respond when people click, type, submit forms and interact with webpage elements.

01. What is an event?

An event is an action or occurrence that happens in the browser. It can be caused by a person interacting with a webpage or by something happening in the browser itself.

Examples of common events include:

  • Clicking a button.
  • Typing into an input field.
  • Submitting a form.
  • Moving a mouse over an element.
  • Pressing a keyboard key.

02. What is an event listener?

An event listener waits for a particular event to happen on an element. When that event occurs, JavaScript runs a function that you've connected to it.

The method used most often is addEventListener(). 

button.addEventListener("click", function() {

    console.log("Button clicked!");

});

This tells the browser to run the function whenever the button receives a click event.

03. Connecting a button to JavaScript

First, create a button in your HTML document. Give it an ID so JavaScript can find it. 

<button id="hello-button">
    Click Me
</button>

Next, find the button in JavaScript using document.querySelector(). We'll explore the DOM in much more depth in Stage 03. 

const button = document.querySelector("#hello-button");

button.addEventListener("click", function() {

    alert("Hello from JavaScript!");

});

When someone clicks the button, the browser displays an alert.

Remember: The HTML element must exist before your JavaScript tries to use it. One easy approach is to load an external script with the defer attribute.

04. Common event types

click Mouse click button.addEventListener("click", ...)
input Input value changes input.addEventListener("input", ...)
submit Form submission form.addEventListener("submit", ...)
keydown Keyboard key pressed document.addEventListener("keydown", ...)
mouseover Pointer enters an element element.addEventListener("mouseover", ...)

05. Responding to typed input

You can listen for changes in an input field. The input event fires as the user changes its value.

Start with this HTML:

<input id="name-input" type="text" placeholder="Enter your name">

<p id="live-output">Your name will appear here.</p>

Now add this JavaScript:

const nameInput = document.querySelector("#name-input");

const output = document.querySelector("#live-output");

nameInput.addEventListener("input", function(event) {

    output.textContent = event.target.value;

});

Every time the input value changes, the event listener runs. The typed text is then placed inside the paragraph.

06. Understanding the event object

When an event occurs, the browser can pass useful information about it to your function. This information is available through an event object, often named event or e. 

button.addEventListener("click", function(event) {

    console.log(event);

});

The event object includes information about what happened and which element triggered the event.

For example, event.target refers to the element that triggered the event.

07. Working with form submissions

Forms often submit information. You can listen for the submit event and control what happens next. 

const form = document.querySelector("#signup-form");

form.addEventListener("submit", function(event) {

    event.preventDefault();

    console.log("Form submitted!");

});

The method preventDefault() stops the browser's normal action for that event. In this example, it prevents the form's default submission behaviour.

Important: preventDefault() is useful when you want JavaScript to handle a form submission yourself. It doesn't automatically validate the form or send information to a server.

08. Putting it all together

Let's create a tiny button counter. Each click increases a number.

HTML:

<h2 id="counter">0</h2>

<button id="increase-button">
    Increase
</button>

JavaScript:

let count = 0;

const counter = document.querySelector("#counter");

const increaseButton = document.querySelector("#increase-button");

increaseButton.addEventListener("click", function() {

    count++;

    counter.textContent = count;

});

Here's what happens:

  • The count variable starts at zero.
  • JavaScript finds the counter and button.
  • An event listener waits for a click.
  • Every click increases count by one.
  • The displayed number is updated.

THE KEY IDEA

Events allow JavaScript to react to user actions. Event listeners connect those actions to functions.
