LESSON 01 / THE BEGINNING

Introduction to CSS

What is CSS, why does it exist, and how does it work with HTML?

01. What exactly is CSS?

CSS stands for Cascading Style Sheets. It is the language used to control how HTML elements look and how they are arranged on a webpage.

HTML creates the structure of a webpage. CSS transforms that structure into a visual experience.

HTML

The Structure

Headings, paragraphs, images, links and buttons.

CSS

The Appearance

Colors, spacing, layouts, typography and animations.

02. How does CSS work?

CSS works by selecting HTML elements and applying visual rules to them.

A basic CSS rule looks like this:

h1 {
    color: lavender;
    font-size: 36px;
}

Let's break it down:

  • h1 — The selector. It identifies the element.
  • color — The property being changed.
  • lavender — The value assigned to that property.
  • font-size — Another property.
  • 36px — Its assigned value.

03. Three ways to add CSS

There are three main ways to apply CSS to HTML.

01 — Inline CSS

CSS is written directly inside an HTML element.

<h1 style="color: lavender;">
    Hello World
</h1>
Useful for quick experiments, but difficult to maintain across larger projects.

02 — Internal CSS

CSS is written inside a style element in the HTML document.

<style>
    h1 {
        color: lavender;
    }
</style>
Useful when styling a single standalone HTML document.

03 — External CSS

CSS is stored in a separate .css file and connected to HTML.

<link rel="stylesheet" href="style.css">
The recommended approach for most multi-page projects.
THE KEY IDEA

HTML builds the page. CSS gives it its visual identity.

LESSON 02 / TARGETING ELEMENTS

Selectors & Specificity

Learn how to target elements and understand which CSS rule wins.

01. What are selectors?

A selector tells CSS which HTML element or elements should receive a particular set of styles.

02. The essential selectors

Element Selector

Targets every element of a particular HTML type.

p {
    color: white;
}
Targets all paragraph elements.

Class Selector

Targets elements that share a class name.

.card {
    background: #191919;
}
A class selector begins with a dot.

ID Selector

Targets an element using its unique ID.

#main-title {
    font-size: 40px;
}
An ID selector begins with a hash.

Universal Selector

Targets all elements on the page.

* {
    box-sizing: border-box;
}

03. Understanding specificity

Sometimes multiple CSS rules target the same element. Specificity helps the browser decide which declaration takes priority. 

p {
    color: white;
}

.description {
    color: lavender;
}

#intro {
    color: cyan;
}

If a paragraph has both the class "description" and the ID "intro", the ID selector wins among these three rules.

ELEMENT Lowest

p

CLASS Higher

.description

ID Highest

#intro

This is a simplified comparison. CSS specificity uses a scoring system, and source order, inheritance, importance and cascade layers can also affect the final result.

THE KEY IDEA

Selectors choose the target. Specificity helps determine which rule takes priority.

LESSON 03 / VISUAL LANGUAGE

Colors, Units & Typography

Build visual identity through color, measurements and text.

01. Working with colors

CSS provides several ways to define colors. The most common formats include named colors, hexadecimal values, RGB and HSL. 

h1 {
    color: lavender;
}

.card {
    background-color: #191919;
}

button {
    color: rgb(255, 255, 255);
}

body {
    background-color: hsl(260, 20%, 8%);
}

02. Understanding CSS units

Units determine measurements such as width, height, spacing and font size.

px — Pixels

A fixed CSS length unit.

padding: 20px;

% — Percentage

Usually calculated relative to a containing element.

width: 80%;

rem — Root em

Relative to the root element's font size.

font-size: 2rem;

em — Relative unit

Relative to the computed font size of the relevant context.

padding: 1.5em;

vh and vw

Relative to the viewport's height and width.

min-height: 100vh;
width: 100vw;

03. Typography

Typography controls how text appears. It includes font families, sizes, weights, spacing and alignment. 

h1 {
    font-family: Arial, sans-serif;
    font-size: 42px;
    font-weight: 700;
    letter-spacing: -1px;
    text-align: center;
}

p {
    line-height: 1.7;
}
  • font-family — Chooses the typeface.
  • font-size — Controls text size.
  • font-weight — Controls text thickness.
  • letter-spacing — Adjusts space between letters.
  • line-height — Controls the height of text lines.
  • text-align — Controls horizontal text alignment.
THE KEY IDEA

Color creates atmosphere. Units control scale. Typography communicates personality.

LESSON 04 / ELEMENT STRUCTURE

The Box Model

Understand how every HTML element occupies space on a webpage.

01. Everything is a box

In CSS, every element is represented by a rectangular box. The CSS box model describes how its dimensions and surrounding space are calculated.

02. The four layers

MARGIN
BORDER
PADDING
CONTENT

01 — Content

The actual content, such as text or an image.

02 — Padding

Space between the content and its border.

03 — Border

The boundary surrounding the padding and content.

04 — Margin

Space outside the border, separating the element from others.

03. Putting it into CSS

.card {
    width: 300px;
    padding: 20px;
    border: 2px solid lavender;
    margin: 30px;
}

By default, the declared width applies to the content box. Padding and borders are added outside that width.

04. Enter box-sizing

The property box-sizing changes how the browser calculates an element's dimensions. 

* {
    box-sizing: border-box;
}

With border-box, the declared width and height include the content, padding and border. This makes layouts easier to manage.

THE KEY IDEA

Content, padding, border and margin work together to determine the space an element occupies.
