LESSON 01 / STAGE 01 THE BEGINNING

Introduction to HTML

Before we create beautiful websites, we need to understand what actually makes a webpage exist.

So, what exactly is HTML?

HTML stands for HyperText Markup Language. It is the standard language used to create the structure of webpages.

Think of a website as a building. HTML creates the structure: the walls, rooms, doors and different spaces. CSS controls how everything looks, while JavaScript makes the website interactive.

HTML is not a programming language. It is a markup language because it uses elements and tags to describe the content of a webpage.

01 / STRUCTURE

HTML

Defines the content and structure of a webpage.

02 / APPEARANCE

CSS

Controls colours, layouts, spacing and visual design.

03 / INTERACTION

JavaScript

Adds behaviour, logic and interactive features.

Your first HTML document

An HTML document is usually saved with the .html file extension. A browser reads this document and turns its code into the webpage you see.

Let's start with a very simple example.

YOUR FIRST HTML PAGE HTML 
<!DOCTYPE html>
<html>

    <head>
        <title>My First Website</title>
    </head>

    <body>
        <h1>Hello, World!</h1>
        <p>This is my first webpage.</p>
    </body>

</html>

What happens when the browser reads this?

The browser reads the HTML document from top to bottom. It recognises the elements and uses them to construct the visible webpage.

The title appears in the browser tab. The heading and paragraph appear inside the webpage itself.

This is my first webpage.

LESSON 02 / STAGE 01 THE BUILDING BLOCKS

Elements and Tags

HTML is made up of elements. Let's understand how these elements are written and how they work together.

What is an HTML tag?

A tag is a piece of markup written inside angle brackets. It tells the browser what kind of element is being used.

For example, <p> is a paragraph opening tag, while </p> is its closing tag.

Most HTML elements have an opening tag, some content, and a closing tag.

ANATOMY OF AN ELEMENT HTML 
<p>This is a paragraph.</p>
<p> Opening tag
This is a paragraph. Content
</p> Closing tag

Elements inside elements

HTML elements can be placed inside other HTML elements. This is called nesting.

Imagine a webpage body containing a heading and a paragraph. Both elements are nested inside the body.

NESTED ELEMENTS HTML 
<body>

    <h1>My Website</h1>

    <p>Welcome to my website.</p>

</body>

What are void elements?

Not every HTML element needs a closing tag. Some elements do not wrap around content. These are called void elements.

An example is the line break element: <br>.

VOID ELEMENT EXAMPLE HTML 
<p>
    First line
    <br>
    Second line
</p>

Common mistakes to avoid

  • Forgetting to close an element that needs a closing tag.
  • Placing elements in the wrong nesting order.
  • Mixing up opening and closing tags.
  • Using a closing tag for a void element.

Remember: properly nested elements should close in the reverse order in which they were opened.

LESSON 03 / STAGE 01 CONTENT AND HIERARCHY

Headings and Paragraphs

A good webpage needs more than content. It needs organisation. Headings and paragraphs help us create it.

Understanding headings

HTML provides six heading levels, from <h1> to <h6>.

These headings create a hierarchy. The main heading introduces the page, while smaller headings organise the different sections underneath it.

A heading is not just text that looks big. It communicates the structure and importance of the content.

H1 / MAIN HEADING

Welcome to My Website

H2 / SECTION HEADING

About Me

H3 / SUBSECTION

My Interests

H4 / SMALLER SECTION

Football

H5
My Favourite Team
H6
More Information

How heading hierarchy works

Think of headings like the chapters and subchapters of a book. A main heading introduces a topic. A smaller heading introduces a part of that topic.

You should choose heading levels based on the structure of your content, not just their appearance.

HEADING HIERARCHY HTML 
<h1>My Website</h1>

    <h2>About Me</h2>

        <h3>My Hobbies</h3>

        <h3>My Goals</h3>

    <h2>Contact</h2>

Now, what are paragraphs?

Paragraphs are used to organise blocks of written text. In HTML, we create them using the <p> element.

Instead of putting an entire article into one long block of text, paragraphs allow us to separate different ideas and make content easier to read.

PARAGRAPH EXAMPLE HTML 
<h1>The World of Football</h1>

<p>
    Football is played and enjoyed
    by millions of people worldwide.
</p>

<p>
    It brings people together through
    teams, competitions and passion.
</p>

Common mistakes

  • Using headings only because you want larger text.
  • Skipping heading levels without a structural reason.
  • Using multiple main headings without considering the page's content structure.
  • Forgetting to close paragraph elements.

LESSON 04 / STAGE 01 GIVING TEXT MEANING

Text Formatting

Sometimes, ordinary text is not enough. HTML gives us elements that help highlight, emphasise and communicate the meaning of specific words.

Why do we format text?

Imagine reading an entire webpage where every word looks and feels exactly the same. It would be difficult to identify important information.

Text formatting allows us to give certain words additional meaning. We can emphasise an important statement, highlight a term or show that something has been deleted or inserted.

HTML provides several elements for this purpose. Let's explore some of the most useful ones.

01 / STRONG IMPORTANCE

<strong>

This text is important.

Communicates that the content has strong importance.
02 / EMPHASIS

<em>

This text is emphasised.

Adds emphasis to a word or phrase.
03 / HIGHLIGHT

<mark>

This text is highlighted.

Marks text that deserves attention.
04 / DELETED TEXT

<del>

This text was deleted.

Represents content that has been removed.
05 / INSERTED TEXT

<ins>

This text was inserted.

Represents content that has been added.
06 / SMALLER TEXT

<small>

This text is smaller.

Used for side comments and less prominent text.

Formatting versus appearance

You might notice that some of these elements change how text looks. However, their purpose is not simply to make text bold, italic or highlighted.

For example, <strong> communicates importance, while <em> communicates emphasis. Their meaning can also be understood by assistive technologies.

If you only want to change how text looks, CSS is generally the right tool for that job.

FORMATTING IN ACTION HTML 
<h1>Important Announcement</h1>

<p>
    Please read the
    <strong>important instructions</strong>
    carefully.
</p>

<p>
    This is <em>really important</em>.
</p>

<p>
    Remember to bring your
    <mark>notebook</mark>.
</p>

<p>
    Original price:
    <del>₹1000</del>
    <ins>₹800</ins>
</p>
BROWSER OUTPUT PREVIEW

Important Announcement

Please read the important instructions carefully.

This is really important.

Remember to bring your notebook.

Original price: ₹1000 ₹800

Let's understand the difference

Here is a quick way to remember the elements:

  • <strong> — important information.
  • <em> — emphasised information.
  • <mark> — highlighted information.
  • <del> — removed information.
  • <ins> — inserted information.
  • <small> — smaller side information.
