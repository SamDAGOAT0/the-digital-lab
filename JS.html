001 / THE NEXT STEP

HTML created the structure.
CSS shaped the experience.
JavaScript makes it alive.

A button that responds to a click. A menu that opens when you need it. A website that changes as you interact with it. JavaScript makes these experiences possible.

In this chapter, you'll learn programming fundamentals, work with logic and events, control HTML elements and eventually build your own interactive web experiences.

002 / COURSE CONTENT

THE CURRICULUM.

12 LESSONS / 03 STAGES
STAGE 01

The Foundations

Understand the language, its building blocks and how JavaScript works.

01 Introduction to JavaScript Discover what JavaScript is and how it makes websites interactive. 02 Variables & Constants Store information and understand let, const and variable naming. 03 Data Types & Values Explore strings, numbers, booleans and other fundamental data types. 04 Operators & Expressions Work with calculations, comparisons and logical operators.
STAGE 02

Logic & Interaction

Give your code the ability to make decisions, repeat actions and respond to people.

05 Conditional Statements Teach your code to make decisions using if, else and switch. 06 Loops & Repetition Repeat instructions and work with for and while loops. 07 Functions Create reusable blocks of code, pass parameters and return values. 08 Events & Event Listeners Make your website respond to clicks, keyboard input and user actions.
STAGE 03

DOM & Visual Mastery

Connect JavaScript to your webpage and create complete interactive experiences.

09 Understanding the DOM Learn how JavaScript finds and interacts with HTML elements. 10 Changing Content & Styles Update text, change styles and control webpage elements dynamically. 11 Building Interactive Components Combine events and DOM manipulation to create useful website features. 12 Final Project Build a complete interactive webpage using everything you've learned.
