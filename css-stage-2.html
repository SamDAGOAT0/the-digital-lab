LESSON 05 / ELEMENT BEHAVIOUR

Display & Positioning

Understand how HTML elements behave in a layout and how CSS controls their position.

01. Understanding display

The display property determines how an element participates in the layout of a webpage. Different display values produce different behaviours.

02. The essential display values

01 — Block

A block element starts on a new line and normally occupies the available width of its containing block. 

div {
    display: block;
}
Common examples include div, section, article and p.

02 — Inline

Inline elements flow within the surrounding text and generally occupy only the space their content needs. 

span {
    display: inline;
}
Common examples include span, a and strong.

03 — Inline-block

Combines inline flow with the ability to set dimensions and other box properties. 

.button {
    display: inline-block;
    width: 150px;
    padding: 12px;
}

04 — None

Removes the element from the layout entirely. It does not occupy space while display is set to none. 

.hidden {
    display: none;
}

03. Understanding positioning

The position property controls how an element is placed in relation to its normal position, containing block or viewport.

Static

The default positioning behaviour. The element follows the normal document flow. 

.element {
    position: static;
}

Relative

Keeps the element in the normal flow but allows it to be visually offset from its original position. 

.element {
    position: relative;
    top: 10px;
    left: 15px;
}

Absolute

Removes the element from normal document flow and positions it relative to its nearest qualifying positioned ancestor. 

.parent {
    position: relative;
}

.child {
    position: absolute;
    top: 10px;
    right: 10px;
}

Fixed

Positions an element relative to the viewport. It generally stays in the same place while scrolling. 

.navbar {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
}

Sticky

Behaves like a relatively positioned element until it reaches a specified scrolling threshold. 

.sidebar {
    position: sticky;
    top: 20px;
}

04. Enter z-index

When elements overlap, z-index can control their stacking order. A higher stacking level generally appears in front of a lower one within the relevant stacking context. 

.background {
    position: relative;
    z-index: 1;
}

.foreground {
    position: relative;
    z-index: 2;
}
THE KEY IDEA

Display determines how elements participate in a layout. Positioning controls where they appear.

LESSON 06 / FLEXIBLE LAYOUTS

Flexbox

Learn how to align, distribute and organize elements using a powerful one-dimensional layout system.

01. What is Flexbox?

Flexbox, short for Flexible Box Layout, is a CSS layout system designed to arrange elements along a single main axis at a time.

It makes alignment, spacing and distribution much easier than relying on older layout techniques.

02. Activating Flexbox

To use Flexbox, first turn an element into a flex container. Its direct children automatically become flex items. 

.container {
    display: flex;
}

03. Understanding the axes

Flexbox works with two axes: the main axis and the cross axis. Their directions depend on flex-direction.

MAIN AXIS

Primary direction

The direction in which flex items are arranged. It is horizontal by default.

CROSS AXIS

Perpendicular direction

The axis that runs perpendicular to the main axis.

04. flex-direction

Determines the direction in which flex items are placed inside the container. 

.container {
    display: flex;
    flex-direction: row;
}

/* Other values */

flex-direction: column;
flex-direction: row-reverse;
flex-direction: column-reverse;

05. justify-content

Controls how flex items are distributed along the main axis. 

.container {
    display: flex;
    justify-content: center;
}

/* Other useful values */

justify-content: flex-start;
justify-content: flex-end;
justify-content: space-between;
justify-content: space-around;
justify-content: space-evenly;

06. align-items

Aligns flex items along the cross axis within the flex container. 

.container {
    display: flex;
    align-items: center;
}

/* Other values */

align-items: flex-start;
align-items: flex-end;
align-items: stretch;
align-items: baseline;

07. gap and flex-wrap

Gap controls the spacing between flex items. Flex-wrap determines whether items can move onto another line when space is limited. 

.container {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
}

08. A complete Flexbox example

.navigation {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 20px;
    padding: 20px;
}

.navigation-links {
    display: flex;
    gap: 15px;
}

This is a common pattern for building website navigation bars.

THE KEY IDEA

Flexbox gives you control over alignment, spacing and direction along a flexible axis.

LESSON 07 / TWO-DIMENSIONAL LAYOUTS

CSS Grid

Build complex layouts using rows, columns and precise control over available space.

01. What is CSS Grid?

CSS Grid is a two-dimensional layout system. It allows you to organize elements using both rows and columns at the same time.

While Flexbox focuses on one dimension, Grid is especially useful for larger page structures.

02. Creating a grid container

Start by setting display to grid. Direct children then become grid items. 

.container {
    display: grid;
}

03. Defining columns

The grid-template-columns property determines how many columns exist and how much space each column receives. 

.container {
    display: grid;
    grid-template-columns: 1fr 1fr;
}

The fr unit represents a fraction of the available space in the grid container.

04. Defining rows

Grid rows can be controlled using grid-template-rows. 

.container {
    display: grid;
    grid-template-columns: 1fr 1fr;
    grid-template-rows: 150px 200px;
}

05. The power of repeat()

Instead of writing the same column size repeatedly, use the repeat() function. 

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
}

06. Understanding gap

Gap controls the space between rows and columns. 

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

/* Separate row and column gaps */

row-gap: 15px;
column-gap: 25px;

07. Spanning multiple columns

Grid items can occupy more than one column or row using grid-column and grid-row. 

.featured-card {
    grid-column: span 2;
}

.tall-card {
    grid-row: span 2;
}

08. Responsive grids with auto-fit

Grid can automatically create as many columns as fit inside the available space. 

.container {
    display: grid;
    grid-template-columns:
        repeat(auto-fit, minmax(220px, 1fr));
    gap: 20px;
}

This is an especially useful technique for responsive card layouts.

09. Grid or Flexbox?

FLEXBOX

One dimension

Best for navigation bars, button groups, alignment and linear arrangements.

CSS GRID

Two dimensions

Best for page layouts, dashboards, galleries and structured card systems.

THE KEY IDEA

Grid gives you control over rows and columns. Flexbox gives you control over a single layout axis.

LESSON 08 / ADAPTIVE EXPERIENCES

Responsive Design

Create websites that remain usable and visually consistent across different screen sizes.

01. What is responsive design?

Responsive design is an approach to web development where layouts adapt to the available screen space.

A responsive website should work comfortably on desktop computers, tablets and smartphones.

02. Start with the viewport

The viewport meta tag tells mobile browsers how to control the dimensions and scaling of a webpage. 

<meta name="viewport"
content="width=device-width, initial-scale=1.0">

This tag is normally placed inside the HTML head element.

03. Flexible measurements

Fixed dimensions can cause problems when a screen becomes smaller. Flexible measurements help layouts adapt naturally. 

.container {
    width: 90%;
    max-width: 1100px;
    margin: 0 auto;
}

04. Understanding media queries

Media queries allow CSS rules to apply only when certain conditions are met, such as a particular viewport width. 

/* Desktop styles */

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
}

/* Smaller screens */

@media (max-width: 768px) {

    .container {
        grid-template-columns: repeat(2, 1fr);
    }

}

05. Mobile layouts

On narrow screens, multi-column layouts may need to become a single column. 

@media (max-width: 480px) {

    .container {
        grid-template-columns: 1fr;
    }

    h1 {
        font-size: 32px;
    }

}

06. Responsive images

Images should not overflow their containing elements. A common approach is to make them flexible. 

img {
    max-width: 100%;
    height: auto;
}

07. Mobile-first design

Mobile-first development means designing the basic layout for smaller screens first, then adding enhancements for larger screens. 

/* Base mobile styles */

.container {
    display: grid;
    grid-template-columns: 1fr;
    gap: 15px;
}

/* Larger screens */

@media (min-width: 768px) {

    .container {
        grid-template-columns: repeat(2, 1fr);
    }

}

@media (min-width: 1100px) {

    .container {
        grid-template-columns: repeat(3, 1fr);
    }

}

08. The responsive design checklist

  • Use a viewport meta tag.
  • Prefer flexible widths where appropriate.
  • Use media queries when layouts need to change.
  • Make images scale within their containers.
  • Keep text readable on smaller screens.
  • Test layouts at multiple viewport sizes.
THE KEY IDEA

A good website doesn't just look great on one screen. It adapts to the screen it's being viewed on.
