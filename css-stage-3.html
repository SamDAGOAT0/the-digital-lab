LESSON 09 / VISUAL DESIGN

Backgrounds, Borders & Shadows.

Learn to create atmosphere, define surfaces and add depth to your designs.

THE CONCEPT

Give your elements a visual identity.

Backgrounds establish the atmosphere of an interface. Borders define its boundaries, while shadows create the illusion of depth.

◈
Backgrounds

Apply colours, images and gradients behind elements.

▢
Borders

Define edges, shapes and visual boundaries.

✧
Shadows

Add depth and separation between surfaces.

CSS / SURFACE DESIGN LIVE EXAMPLE 
.design-card {
    background:
        linear-gradient(
            135deg,
            #8b5cf6,
            #2563eb
        );

    border: 1px solid
        rgba(255,255,255,0.2);

    border-radius: 20px;

    box-shadow:
        0 15px 40px
        rgba(80,50,180,0.3);
}
THE RESULT
Beautifully layered.

Colour. Shape. Depth.

LESSON 10 / MOTION DESIGN

Transitions & Animations.

Static interfaces are only the beginning. Give your designs movement and personality.

THE CONCEPT

Make every interaction feel alive.

Transitions create smooth changes between CSS property values. Animations let you define sequences of movement using keyframes.

↔
Transitions

Control how smoothly a property changes.

⟳
Keyframes

Define the stages of an animation.

✦
Timing Functions

Control the speed and rhythm of movement.

CSS / MOTION DESIGN LIVE EXAMPLE 
.motion-button {
    transition:
        transform 0.3s ease,
        box-shadow 0.3s ease;
}

.motion-button:hover {
    transform: translateY(-5px);

    box-shadow:
        0 12px 30px
        rgba(150,100,255,0.3);
}

@keyframes float {
    0%, 100% {
        transform: translateY(0);
    }

    50% {
        transform: translateY(-12px);
    }
}

LESSON 11 / ADVANCED CSS

Advanced CSS & Pseudo-classes.

Explore more powerful selectors and learn how to style elements based on their state.

THE CONCEPT

Write smarter, more expressive CSS.

Advanced selectors allow you to target elements based on relationships, structure and interaction states — without adding unnecessary classes everywhere.

:
Pseudo-classes

Style elements based on states like hover and focus.

::
Pseudo-elements

Style specific parts of an element.

⌘
Advanced Selectors

Target elements using relationships and conditions.

CSS / SELECTOR POWER LIVE EXAMPLE 
/* Interaction states */

button:hover {
    background: #8b5cf6;
}

input:focus {
    border-color: #83cfff;
}

/* Structural selectors */

li:first-child {
    color: #b69aff;
}

/* Pseudo-elements */

h2::after {
    content: " ✦";
}
