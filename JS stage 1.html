LESSON 01 / THE BEGINNING

Introduction to JavaScript

What is JavaScript, why does it exist, and how does it work with HTML and CSS?

01. What exactly is JavaScript?

JavaScript is a programming language used to make websites interactive and dynamic. It allows a webpage to respond to actions, process information and change what appears on the screen.

Think about a website with a menu button. HTML creates the button, CSS controls how it looks, and JavaScript can make the menu open when someone clicks it.

HTML

The Structure

Creates headings, paragraphs, buttons, images and other elements.

CSS

The Appearance

Controls colours, layouts, typography and visual design.

JAVASCRIPT

The Behaviour

Adds logic, interaction, calculations and dynamic behaviour.

02. What can JavaScript actually do?

JavaScript can control many parts of a website. Here are some everyday examples:

  • Open and close navigation menus.
  • Respond to clicks and keyboard input.
  • Validate information entered into forms.
  • Update text and images without reloading the page.
  • Create animations and interactive components.
  • Build games, tools and web applications.

03. Your first JavaScript instruction

One of the simplest ways to start using JavaScript is with console.log(). It prints information into the browser's developer console. 

console.log("Hello, world!");

console.log("Welcome to JavaScript.");

console.log(10 + 5);

The browser evaluates each instruction. The console displays the results:

CONSOLE OUTPUT Hello, world! Welcome to JavaScript. 15

To open the developer console in Chrome, press F12 and select the Console tab.

04. Connecting JavaScript to HTML

JavaScript can be written directly inside an HTML document, but larger projects usually use a separate JavaScript file.

Let's imagine you have two files:

PROJECT FILES index.html script.js

Inside your HTML document, connect the JavaScript file using a script element: 

<script src="script.js" defer></script>

The src attribute tells the browser where to find the JavaScript file. The defer attribute tells the browser to run the script after the HTML document has been parsed.

05. Your first JavaScript file

Open script.js and write: 

console.log("My first JavaScript file!");

console.log("I am learning to make websites interactive.");

Save both files, open your HTML page in the browser and check the Console tab. You should see your messages.

THE KEY IDEA

HTML structures a webpage, CSS styles it, and JavaScript gives it behaviour.

LESSON 02 / STORING INFORMATION

Variables & Constants

Learn how to store information, give it a name and use it throughout your code.

01. What is a variable?

A variable is a named place in your program where a value can be stored. It allows you to save information and use that information again whenever you need it.

Imagine building a football scoreboard. You need to remember the names of the teams and their current scores. Variables can store all of that information. 

let teamName = "Barcelona";

let score = 2;

console.log(teamName);
console.log(score);
CONSOLE OUTPUT Barcelona 2

02. Creating variables with let

The let keyword creates a variable whose value can be reassigned. 

let score = 0;

score = 1;

score = 2;

console.log(score);

We first created score with a value of 0. Then we changed its value twice. The final output is 2.

Remember: You use let when a variable's value is expected to change.

03. Creating constants with const

The const keyword creates a variable binding that cannot be reassigned. 

const club = "Barcelona";

console.log(club);

The value stored in club can be read and used, but you cannot assign a completely different value to that const variable later.

For example, trying to write club = "Argentina" would produce an error.

Remember: Use const when you don't intend to reassign the variable.

04. let vs const

LET

Can be reassigned

let level = 1;

level = 2;
CONST

Cannot be reassigned

const maxLevel = 10;

// Reassignment is not allowed.

05. Naming your variables

Variable names should explain what information they hold. 

let playerName = "Alex";

let currentScore = 120;

const maximumAttempts = 3;

JavaScript commonly uses a naming style called camelCase. The first word starts with a lowercase letter, and each following word begins with a capital letter.

GOOD VARIABLE NAMES playerName totalPrice currentLevel AVOID UNCLEAR NAMES x thing abc

Some naming rules are important:

  • Names cannot begin with a number.
  • Spaces are not allowed in variable names.
  • JavaScript keywords cannot be used as variable names.
  • Variable names are case-sensitive.

THE KEY IDEA

LESSON 03 / UNDERSTANDING VALUES

Data Types & Values

Discover the different kinds of information JavaScript can work with.

01. What are data types?

Every value in JavaScript has a data type. A data type describes what kind of information a value represents and what operations can be performed with it.

For example, a person's name is text, their age is a number, and whether a door is open can be represented as true or false.

02. Strings

A string is text. It can contain letters, numbers, spaces and symbols. Strings are written inside quotation marks. 

let player = "Lamine Yamal";

let country = 'Spain';

let message = "Welcome to the lab!";

console.log(player);
console.log(country);
console.log(message);

Single quotes and double quotes can both create strings. Just make sure the opening and closing quotation marks match.

03. Numbers

The number type is used for numerical values. JavaScript uses one main number type for regular whole numbers and decimal numbers. 

let age = 14;

let price = 99.50;

let temperature = -5;

console.log(age);
console.log(price);

You don't need quotation marks around numbers when you want JavaScript to treat them as numerical values.

04. Booleans

A Boolean has only two possible values: true or false. Booleans are especially useful when your program needs to keep track of a condition. 

let isLoggedIn = true;

let hasAccess = false;

console.log(isLoggedIn);
console.log(hasAccess);

For example, a website can use a Boolean to remember whether someone is logged in.

05. Undefined

A variable that has been declared but hasn't been assigned a value is undefined. 

let username;

console.log(username);
CONSOLE OUTPUT undefined

06. Null

Null represents the intentional absence of a value. 

let selectedPlayer = null;

console.log(selectedPlayer);

The difference is that undefined often means a value hasn't been assigned, while null is a value deliberately used to represent "nothing" or "no current value".

07. Objects

Objects let you group related information together using named properties. 

const player = {
    name: "Lamine Yamal",
    club: "Barcelona",
    age: 18
};

console.log(player.name);
console.log(player.club);

Instead of keeping each detail in a separate variable, an object groups information about one player.

08. Arrays

An array stores an ordered collection of values. 

const clubs = [
    "Barcelona",
    "Arsenal",
    "Bayern Munich"
];

console.log(clubs[0]);
console.log(clubs[1]);

Array positions start at zero. That means clubs[0] gives you the first item, while clubs[1] gives you the second.

09. Checking data types

JavaScript includes an operator called typeof, which helps you identify the type of a value. 

console.log(typeof "Hello");

console.log(typeof 25);

console.log(typeof true);

console.log(typeof undefined);
CONSOLE OUTPUT string number boolean undefined
A small JavaScript quirk: typeof null returns "object". This is a historical behaviour of JavaScript. It does not mean null is actually an object.

LESSON 04 / WORKING WITH VALUES

Operators & Expressions

Learn how JavaScript performs calculations, compares information and combines conditions.

01. What are operators?

Operators are symbols or keywords that perform operations on values. They allow JavaScript to calculate, compare and work with information.

For example, the plus sign can add two numbers together. 

let result = 10 + 5;

console.log(result);
CONSOLE OUTPUT 15

02. Arithmetic operators

Arithmetic operators are used to perform mathematical calculations.

+Addition10 + 5 = 15
-Subtraction10 - 5 = 5
*Multiplication10 * 5 = 50
/Division10 / 5 = 2
%Remainder10 % 3 = 1
**Exponentiation2 ** 3 = 8

The remainder operator (%) gives you what remains after a division. 

let remainder = 10 % 3;

console.log(remainder);

03. Assignment operators

Assignment operators allow you to assign values to variables and update them. 

let score = 10;

score += 5;

console.log(score);

The += operator adds a value to the current variable and stores the result back in it. Here, score becomes 15.

=Assignscore = 10
+=Add and assignscore += 5
-=Subtract and assignscore -= 2
*=Multiply and assignscore *= 2
/=Divide and assignscore /= 2

04. Comparison operators

Comparison operators compare two values. Their result is a Boolean: either true or false. 

console.log(10 > 5);

console.log(10 < 5);

console.log(10 === 10);

console.log(10 !== 5);
CONSOLE OUTPUT true false true true

Some common comparison operators:

===Strictly equal5 === 5
!==Strictly not equal5 !== 3
>Greater than8 > 4
<Less than3 < 7
>=Greater or equal8 >= 8
<=Less or equal4 <= 6
Important: Prefer === and !== for equality checks. They compare values without automatically converting between different data types.

05. Logical operators

Logical operators combine or reverse Boolean conditions.

&& AND true && true
|| OR true || false
! NOT !true 
let hasTicket = true;

let isOldEnough = true;

console.log(hasTicket && isOldEnough);

The AND operator (&&) returns true when both conditions are true.

06. What is an expression?

An expression is a piece of code that produces a value. 

10 + 5

score > 100

"Hello " + "world"

Each example produces a value: a number, a Boolean or a string.

07. Combining operators

You can combine multiple operations in one expression. 

let total = 100 + 50 * 2;

console.log(total);

The output is 200, not 300, because multiplication takes priority over addition in this expression.

Use parentheses when you want to control the order: 

let total = (100 + 50) * 2;

console.log(total);
CONSOLE OUTPUT 300
