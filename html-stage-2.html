LESSON 05 / STAGE 02 CONNECTING THE WEB

Links and Navigation

Websites aren't isolated documents. Links connect webpages, resources and entire parts of the internet.

What is a hyperlink?

A hyperlink is a clickable connection that takes a user to another location. It might open another webpage, a different section of the same page, or an external website.

In HTML, we create links using the <a> element, also known as the anchor element.

The most important attribute of an anchor is href. It tells the browser where the link should take the user.

A BASIC LINK 
<a href="https://www.wikipedia.org">
    Visit Wikipedia
</a>

Understanding the href attribute

The href attribute contains the destination of the link.

There are different kinds of destinations. Let's look at three common examples.

  • External link: takes you to another website.
  • Internal link: takes you to another page in your own website.
  • Page section link: jumps to a specific section on the current page.
THREE TYPES OF LINKS 
<!-- External link -->
<a href="https://example.com">
    Visit Example
</a>

<!-- Another page in your website -->
<a href="about.html">
    About Us
</a>

<!-- A section on this page -->
<a href="#contact">
    Contact Section
</a>

<section id="contact">
    <h2>Contact Us</h2>
</section>

Opening links in a new tab

Sometimes you want a link to open in a new browser tab instead of replacing the current page.

You can use target="_blank" to do this. For external links, it's also good practice to use rel="noopener noreferrer".

NEW TAB EXAMPLE 
<a
    href="https://example.com"
    target="_blank"
    rel="noopener noreferrer"
>
    Open Example
</a>

How website navigation works

A navigation bar is simply a group of links that helps visitors move around a website.

You might see links such as Home, About, Projects and Contact at the top of a website. These are usually placed inside a <nav> element.

A SIMPLE NAVIGATION BAR 
<nav>
    <a href="index.html">Home</a>
    <a href="about.html">About</a>
    <a href="projects.html">Projects</a>
    <a href="contact.html">Contact</a>
</nav>
Remember: A link uses <a>, while its destination is specified using the href attribute.

LESSON 06 / STAGE 02 VISUAL CONTENT

Images and Media

A webpage doesn't have to be made of text alone. Images and media make content more visual and expressive.

Adding images to HTML

The <img> element is used to display an image on a webpage.

Unlike a paragraph or heading, an image element does not wrap around content. It is a void element, so it does not need a closing tag.

The two most important image attributes are:

  • src — tells the browser where the image file is located.
  • alt — provides alternative text describing the image.
IMAGE ELEMENT 
<img
    src="football.jpg"
    alt="A football on a field"
>

Understanding image paths

The src attribute can point to an image stored in your project folder or to an image hosted online.

If your image is in the same folder as your HTML file, you can simply use its filename.

If it is inside another folder, include that folder in the path.

IMAGE PATH EXAMPLES 
<!-- Image in the same folder -->
<img src="photo.jpg" alt="A photograph">

<!-- Image inside an images folder -->
<img src="images/photo.jpg" alt="A photograph">

<!-- Image from an online source -->
<img src="https://example.com/photo.jpg"
     alt="An example photograph">

Why is alt text important?

The alt attribute describes an image when it cannot be displayed. Screen readers can also use it to describe images to people who cannot see them.

Good alt text describes the useful information conveyed by the image. Avoid writing vague descriptions such as "image123".

Adding audio and video

HTML also includes elements for audio and video. These allow you to include media without relying entirely on external players.

The <audio> element can display audio controls, while the <video> element can display a video player.

AUDIO AND VIDEO 
<audio controls>
    <source src="music.mp3" type="audio/mpeg">
    Your browser does not support audio.
</audio>

<video controls width="400">
    <source src="video.mp4" type="video/mp4">
    Your browser does not support video.
</video>
Important: The media examples need actual media files at the paths you specify. The controls attribute displays the browser's built-in playback controls.

LESSON 07 / STAGE 02 ORGANISING INFORMATION

Lists

Sometimes information is easier to understand when it is organised into a list instead of a paragraph.

What are HTML lists?

HTML lists allow us to group related items together. They are useful for instructions, menus, features, rankings and many other types of information.

HTML provides three main types of lists:

  • Unordered lists.
  • Ordered lists.
  • Description lists.

01 / Unordered lists

An unordered list displays items without a specific numerical order. Browsers usually show bullet points.

We create one using <ul>. Each item is placed inside an <li> element.

UNORDERED LIST 
<h2>My Favourite Sports</h2>

<ul>
    <li>Football</li>
    <li>Cricket</li>
    <li>Basketball</li>
</ul>

02 / Ordered lists

An ordered list is used when the sequence of items matters. Browsers usually display numbers by default.

We create one using <ol>, with each item again placed inside <li>.

ORDERED LIST 
<h2>How to Make Tea</h2>

<ol>
    <li>Boil water.</li>
    <li>Add tea leaves.</li>
    <li>Add milk and sugar.</li>
    <li>Serve the tea.</li>
</ol>

03 / Description lists

Description lists are useful when you want to show terms alongside their descriptions.

They use three elements:

  • <dl> — the description list.
  • <dt> — the term being described.
  • <dd> — the description itself.
DESCRIPTION LIST 
<dl>

    <dt>HTML</dt>
    <dd>Structures webpages.</dd>

    <dt>CSS</dt>
    <dd>Styles webpages.</dd>

    <dt>JavaScript</dt>
    <dd>Adds interactivity.</dd>

</dl>

Can lists be nested?

Absolutely! You can place one list inside another list item. This creates a nested list.

Nested lists are useful when information has categories and subcategories.

NESTED LIST 
<ul>
    <li>Sports
        <ul>
            <li>Football</li>
            <li>Cricket</li>
        </ul>
    </li>

    <li>Music
        <ul>
            <li>Rock</li>
            <li>Pop</li>
        </ul>
    </li>
</ul>
Remember: Use unordered lists when sequence does not matter, ordered lists when sequence matters, and description lists for terms and explanations.

LESSON 08 / STAGE 02 STRUCTURED DATA

Tables

When information needs to be compared or arranged into rows and columns, HTML tables come into play.

What is an HTML table?

An HTML table organises information into rows and columns. It is useful for schedules, comparisons, results and other structured information.

Tables are built using several elements that work together. Let's understand them one by one.

The main table elements

  • <table> — creates the table.
  • <tr> — creates a table row.
  • <th> — creates a header cell.
  • <td> — creates a regular data cell.
  • <caption> — gives the table a title.
YOUR FIRST TABLE 
<table>

    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>

    <tr>
        <td>Alex</td>
        <td>14</td>
    </tr>

    <tr>
        <td>Jordan</td>
        <td>15</td>
    </tr>

</table>

Understanding table structure

The outer <table> element contains the entire table.

Each <tr> creates a new row. Inside that row, you can add header cells using <th> or regular cells using <td>.

This is how the browser understands which pieces of information belong together.

Organising bigger tables

HTML also provides elements that help divide a table into meaningful sections.

  • <thead> — groups header rows.
  • <tbody> — groups the main data.
  • <tfoot> — groups footer rows.

These elements make larger tables easier to understand and maintain.

A STRUCTURED TABLE 
<table>

    <thead>
        <tr>
            <th>Subject</th>
            <th>Marks</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>Maths</td>
            <td>85</td>
        </tr>

        <tr>
            <td>Science</td>
            <td>92</td>
        </tr>
    </tbody>

</table>

Making tables accessible

A table should communicate what its rows and columns represent. Use meaningful header cells and consider adding a caption.

For more complex tables, attributes such as scope can help browsers and assistive technologies understand the relationship between headers and data.

TABLE WITH CAPTION AND SCOPE 
<table>

    <caption>Weekly Schedule</caption>

    <thead>
        <tr>
            <th scope="col">Day</th>
            <th scope="col">Activity</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <th scope="row">Monday</th>
            <td>Football practice</td>
        </tr>

        <tr>
            <th scope="row">Tuesday</th>
            <td>Study session</td>
        </tr>
    </tbody>

</table>
Remember: Tables are for tabular data, not for building the overall layout of a webpage. CSS is the right tool for page layouts.
