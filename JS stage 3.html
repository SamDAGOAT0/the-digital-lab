LESSON 09 / CONNECTING TO HTML

Understanding the DOM

Discover how JavaScript sees your webpage and learns to find individual HTML elements.

01. What is the DOM?

DOM stands for Document Object Model. It is a programming representation of an HTML document that JavaScript can interact with.

When a browser loads an HTML page, it parses the markup and creates a structured tree of objects. JavaScript can use this structure to find elements, read their information and change the document.

Imagine a webpage containing a heading, a paragraph and a button. The DOM represents these elements and their relationships.

02. Understanding the DOM tree

HTML elements can contain other elements. This creates a parent-child relationship. 

<body>

    <main>

        <h1>Welcome to TDL</h1>

        <p>Learn JavaScript.</p>

        <button>Start Learning</button>

    </main>

</body>

In this example:

  • body is the parent of main.
  • main is the parent of h1, p and button.
  • h1, p and button are child elements of main.

03. The document object

JavaScript accesses the webpage through an object called document. It provides methods and properties that help you work with the HTML page. 

console.log(document);

console.log(document.title);

console.log(document.body);

These instructions let you inspect the document, read its title and access its body element.

04. Selecting elements by ID

Every HTML element can be given an ID. You can use getElementById() to find an element with a particular ID.

HTML:

<h1 id="main-title">
    Welcome to TDL
</h1>

JavaScript:

const title = document.getElementById("main-title");

console.log(title);

JavaScript finds the heading and stores the element in the title variable.

05. Using querySelector()

Another common method is querySelector(). It finds the first element that matches a CSS selector. 

const heading = document.querySelector("h1");

const card = document.querySelector(".card");

const menu = document.querySelector("#menu");

Notice how it uses the same selector symbols as CSS:

CLASS

.card

Finds an element with the class card.

ID

#menu

Finds an element with the ID menu.

06. Selecting multiple elements

What if you want to find every card on the page?

Use querySelectorAll(). It returns a collection of all matching elements. 

const cards = document.querySelectorAll(".card");

console.log(cards);

You can then use forEach() to work with each matching element. 

const cards = document.querySelectorAll(".card");

cards.forEach(function(card) {

    console.log(card);

});

07. Reading element information

Once you've selected an element, you can read useful information from it. 

const heading = document.querySelector("h1");

console.log(heading.textContent);

console.log(heading.id);

console.log(heading.className);

textContent reads the text inside an element. id reads its ID, and className reads its class attribute as a string.

08. Making sure the HTML exists

JavaScript needs to find an element that already exists in the document.

When using an external JavaScript file, the defer attribute is a simple way to make sure the HTML has been parsed before the script runs. 

<script src="script.js" defer></script>

You can also check whether an element was found before using it. 

const button = document.querySelector("#my-button");

if (button) {

    console.log("Button found!");

}

LESSON 10 / CHANGING THE PAGE

Changing Content & Styles

Learn how to update text, modify CSS classes, change styles and create new HTML elements directly through JavaScript.

01. Making a webpage dynamic

So far, you've learned how to find HTML elements using the DOM. Now you'll learn what to do after finding them.

JavaScript can change the contents, appearance and structure of a webpage without needing to reload the entire page.

02. Changing text with textContent

The textContent property lets you read or replace the text inside an element.

HTML:

<h1 id="title">Old Heading</h1>

JavaScript:

const title = document.querySelector("#title");

title.textContent = "Welcome to the Future";

The heading now displays the new text.

03. Understanding innerHTML

innerHTML lets you read or replace the HTML markup inside an element. This means you can insert elements as well as text. 

const container = document.querySelector("#container");

container.innerHTML = "<strong>Hello, world!</strong>";

The browser interprets the supplied string as HTML and creates a strong element inside the container.

Security warning: Avoid placing untrusted user input directly into innerHTML. It can create cross-site scripting vulnerabilities. Use textContent when you only need to display plain text.

04. Changing styles with JavaScript

JavaScript can also modify an element's inline CSS styles using the style property. 

const heading = document.querySelector("h1");

heading.style.color = "yellow";

heading.style.fontSize = "48px";

heading.style.backgroundColor = "#151515";

JavaScript style properties use camelCase. For example, CSS background-color becomes backgroundColor in JavaScript.

05. The better way: classList

Instead of writing lots of individual style changes in JavaScript, you can create CSS classes and control them through classList.

CSS:

.highlight {
    background: #f7df1e;
    color: #090a0c;
    padding: 20px;
    border-radius: 12px;
}

JavaScript:

const card = document.querySelector(".card");

card.classList.add("highlight");

The card now receives the styles from the highlight class.

06. Four useful classList methods

add() Add a class card.classList.add("active");
remove() Remove a class card.classList.remove("active");
toggle() Add or remove a class card.classList.toggle("active");
contains() Check for a class card.classList.contains("active");

07. Changing HTML attributes

HTML elements have attributes such as src, href, alt and title. JavaScript can read and update them. 

const image = document.querySelector("#profile-image");

image.setAttribute("alt", "Player profile");

console.log(image.getAttribute("alt"));

You can also update an image source: 

image.setAttribute("src", "new-image.jpg");

For form controls, the value property is especially useful. 

const username = document.querySelector("#username");

console.log(username.value);

08. Creating new elements

JavaScript can create completely new HTML elements using createElement(). 

const newParagraph = document.createElement("p");

newParagraph.textContent = "Created with JavaScript!";

document.body.appendChild(newParagraph);

Let's break this down:

  • createElement("p") creates a new paragraph element.
  • textContent gives it some text.
  • appendChild() inserts it into the webpage.

09. Removing elements

You can also remove an element from the webpage when it is no longer needed. 

const message = document.querySelector("#message");

message.remove();

This removes the selected element from the document.

10. Bringing it together

Imagine a button that changes a card's appearance when clicked.

HTML:

<div class="card" id="my-card">
    <h2>My Card</h2>
    <p>This card can change.</p>
</div>

<button id="theme-button">
    Change Appearance
</button>

CSS:

.active-card {
    background: #f7df1e;
    color: #090a0c;
    border-radius: 18px;
    padding: 25px;
}

JavaScript:

const card = document.querySelector("#my-card");

const button = document.querySelector("#theme-button");

button.addEventListener("click", function() {

    card.classList.toggle("active-card");

});

Every click switches the active-card class on or off. CSS controls the appearance, while JavaScript controls when the class changes.

THE KEY IDEA

JavaScript can dynamically change content, styles, attributes and even the structure of a webpage.

LESSON 11 / BUILDING EXPERIENCES

Building Interactive Components

Combine the DOM, functions, events and CSS to create components that people can actually interact with.

01. From individual features to components

You've learned how to select elements, update their content and listen for events. Now you can combine these skills to create complete interface components.

A component is a reusable part of an interface that performs a particular job.

Common website components include:

  • Navigation menus.
  • Dropdowns and accordions.
  • Tabs and content panels.
  • Pop-up dialogs and modals.
  • Interactive counters and forms.

02. Building an accordion

An accordion is a component that expands or collapses to show additional information. It is commonly used in FAQs and content sections.

HTML:

<button
    id="faq-button"
    aria-expanded="false"
    aria-controls="faq-answer">

    What is JavaScript?

</button>

<div id="faq-answer" hidden>
    JavaScript makes webpages interactive.
</div>

JavaScript:

const faqButton = document.querySelector("#faq-button");

const faqAnswer = document.querySelector("#faq-answer");

faqButton.addEventListener("click", function() {

    const isOpen =
        faqButton.getAttribute("aria-expanded") === "true";

    faqButton.setAttribute(
        "aria-expanded",
        String(!isOpen)
    );

    faqAnswer.hidden = isOpen;

});

When the button is clicked, JavaScript checks the current state and reverses it. The hidden property controls whether the answer is displayed.

Accessibility tip: aria-expanded communicates whether the accordion is open or closed to assistive technologies. Always keep it synchronized with the actual component state.

03. Building tabs

Tabs let users switch between different content panels without leaving the page.

HTML:

<div class="tabs">

    <button data-tab="overview" aria-selected="true">
        Overview
    </button>

    <button data-tab="details" aria-selected="false">
        Details
    </button>

</div>

<section data-panel="overview">
    Welcome to the overview.
</section>

<section data-panel="details" hidden>
    Here are the details.
</section>

JavaScript:

const tabButtons = document.querySelectorAll("[data-tab]");

const tabPanels = document.querySelectorAll("[data-panel]");

tabButtons.forEach(function(button) {

    button.addEventListener("click", function() {

        const target = button.dataset.tab;

        tabButtons.forEach(function(tab) {

            const selected = tab === button;

            tab.setAttribute(
                "aria-selected",
                String(selected)
            );

        });

        tabPanels.forEach(function(panel) {

            panel.hidden = panel.dataset.panel !== target;

        });

    });

});

The data-tab attribute identifies which content panel a button controls. JavaScript updates the selected state and displays the matching panel.

04. Understanding data attributes

HTML allows you to store custom information using attributes that begin with data-. 

<button data-player="lamine">
    Lamine Yamal
</button>

JavaScript can read the custom value through the dataset property. 

const playerButton = document.querySelector("button");

console.log(playerButton.dataset.player);
CONSOLE OUTPUT lamine

05. Understanding event delegation

Sometimes a page has many buttons that perform similar actions. Instead of adding a separate event listener to every button, you can listen on a parent element and check which child was clicked.

This technique is called event delegation. 

const menu = document.querySelector("#menu");

menu.addEventListener("click", function(event) {

    const button = event.target.closest("button");

    if (!button || !menu.contains(button)) {
        return;
    }

    console.log("Selected:", button.textContent);

});

The closest() method searches for the nearest matching button. The contains() check makes sure the button belongs to the menu.

Event delegation is useful when you have lists of buttons or elements that are created dynamically.

06. Building a modal

A modal is a dialog that appears above the rest of the webpage. It is often used for confirmations, forms and additional information.

HTML:

<button id="open-modal">
    Open Dialog
</button>

<dialog id="info-modal">

    <h2>Welcome!</h2>

    <p>This is an interactive dialog.</p>

    <button id="close-modal">
        Close
    </button>

</dialog>

JavaScript:

const modal = document.querySelector("#info-modal");

const openButton = document.querySelector("#open-modal");

const closeButton = document.querySelector("#close-modal");

openButton.addEventListener("click", function() {

    modal.showModal();

});

closeButton.addEventListener("click", function() {

    modal.close();

});

The browser's dialog element provides built-in methods for opening and closing the modal.

07. Why component thinking matters

Rather than treating a website as one giant block of code, you can split it into smaller parts with clear responsibilities.

COMPONENT

Accordion

Controls whether additional information is visible.

COMPONENT

Tabs

Switches between different content panels.

COMPONENT

Modal

Displays a separate dialog above the page.

COMPONENT

Menu

Organises navigation and responds to user actions.

YOUR PRACTICAL TASK

Build an interactive FAQ section.

Create three questions, each with an answer that can be expanded and collapsed.

  • Use a button for each question.
  • Give each answer its own HTML element.
  • Use event listeners to toggle visibility.
  • Update aria-expanded when answers open or close.
  • Use CSS to make the open state visually clear.

Bonus: Use event delegation so one event listener can handle the questions.

THE KEY IDEA

Interactive components combine HTML, CSS, DOM manipulation and events to create useful website experiences.

06. Step three — Add JavaScript

Now open matchday.js. This is where the dashboard becomes interactive. 

// SELECT THE HTML ELEMENTS

const homeScoreDisplay =
    document.querySelector("#home-score");

const awayScoreDisplay =
    document.querySelector("#away-score");

const homePlus =
    document.querySelector("#home-plus");

const homeMinus =
    document.querySelector("#home-minus");

const awayPlus =
    document.querySelector("#away-plus");

const awayMinus =
    document.querySelector("#away-minus");

const resetButton =
    document.querySelector("#reset-button");

const statusButton =
    document.querySelector("#status-button");

const matchStatus =
    document.querySelector("#match-status");

const themeButton =
    document.querySelector("#theme-button");


// STORE THE SCORES

let homeScore = 0;

let awayScore = 0;


// UPDATE THE SCOREBOARD

function updateScoreboard() {

    homeScoreDisplay.textContent = homeScore;

    awayScoreDisplay.textContent = awayScore;

}


// HOME TEAM CONTROLS

homePlus.addEventListener("click", function() {

    homeScore++;

    updateScoreboard();

});


homeMinus.addEventListener("click", function() {

    if (homeScore > 0) {

        homeScore--;

        updateScoreboard();

    }

});


// AWAY TEAM CONTROLS

awayPlus.addEventListener("click", function() {

    awayScore++;

    updateScoreboard();

});


awayMinus.addEventListener("click", function() {

    if (awayScore > 0) {

        awayScore--;

        updateScoreboard();

    }

});


// MATCH STATUS

const statuses = [
    "UPCOMING",
    "LIVE",
    "FULL TIME"
];

let statusIndex = 0;

statusButton.addEventListener("click", function() {

    statusIndex++;

    if (statusIndex >= statuses.length) {

        statusIndex = 0;

    }

    matchStatus.textContent = statuses[statusIndex];

});


// RESET THE MATCH

resetButton.addEventListener("click", function() {

    homeScore = 0;

    awayScore = 0;

    statusIndex = 0;

    matchStatus.textContent = statuses[statusIndex];

    updateScoreboard();

});


// SWITCH THEME

themeButton.addEventListener("click", function() {

    document.body.classList.toggle("matchday-light");

});
